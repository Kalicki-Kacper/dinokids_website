# Dino Kids website

Public pages for the Dino Kids iOS app, served by GitHub Pages from `main`:

- https://kalicki-kacper.github.io/dinokids_website/
- Privacy Policy: https://kalicki-kacper.github.io/dinokids_website/privacy_policy.html
- Terms of Use: https://kalicki-kacper.github.io/dinokids_website/terms_of_use.html
- Support: https://kalicki-kacper.github.io/dinokids_website/support.html

Every page has English and Polish. English shows by default, and `#pl` (or a Polish browser) shows Polish.
The app links to these URLs from `AppLinks.swift`. Keep the file names stable.
When the app's data handling changes, update `privacy_policy.html` and its date.
